# 🦌 고라니 주의보

비 오는 밤 국도에서 갑자기 튀어나오는 고라니를 피하는 게임입니다.

- ◀ ▶ (← →): 차선 바꾸기
- 🧽 (스페이스): 와이퍼, 꾹 누르고 있기 (너무 쓰면 과열!)
- ❤️ 목숨 3개, 가끔 떨어지는 하트를 먹으면 +1
- 🌏 게임오버 때 이름을 적으면 전체 랭킹에 올라갑니다 (Firebase Firestore)

## 파일
- `index.html`: 게임 전체 (이미지 파일 없이 한 파일)
- `firestore.rules`: 랭킹 보안 규칙 (Firebase 콘솔 → Firestore → 규칙 탭에 붙여넣기)
